  ## Description
  
  simple command line app that builds high quality README based on project details.

  ## Installation
  
  Download project files, open folder in terminal, run'npm install' to set up.
  
  ## Usage
  
  After installing, run 'node index.js' and answer all questions. After a custon ReadME will be created.
